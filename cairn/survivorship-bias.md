# 固定池回測的倖存者偏差（本專案反覆發生）

## 症狀

回測績效**遠優於**誠實重測或實盤,數字漂亮到可疑。本專案已發生至少三次：

1. **全輪替 2015-2025 回測**：用「今天的市值排名」套到過去 → 發現後改用歷史股本重建（build_historical_shares.py）。
2. **法人動能 2022-2026-07**：固定池（今天的市值前 150）+303.74% → 逐季當時市值池 **+2.65%**（2026-08-11 驗證）。
3. README 歷史上的 +85.22%、+133.89% 宣稱與後續重測的落差,部分亦與此類選擇偏差相關。

## 根因

候選池固定用「**今天的**市值前 N」套用到過去 = **內含未來贏家**（當時還小、後來變大的股票）,等於用 2026 的答案考 2022 的試卷（開卷考試）。實測：2022 vs 2026 前 150 大重疊僅 81%（29 檔換血）,而固定池績效的引擎正是那 29 檔「未來贏家」（如華城/中興電/士電,2022 年後漲 10-30 倍）。

## 偵測方法

1. 比對「今天前 N」與「當年當時前 N」的重疊率（<90% 就要警覺）。
2. 檢視回測獲利集中度：獲利是否主要由「今天才變大的股票」貢獻。
3. 直接對照：同一區間跑固定池 vs 逐季池,差距 >2 倍即為偏差主導。

## 防護（已實作）

- `core/inst_strategy_core.py::build_quarterly_pool`：當時市值 = 歷史股本（historical_shares.pkl）× 當季收盤價 → 逐季排序取前 N。
- 回測候選池一律用逐季池（歷史股本庫存在時自動啟用）；實盤用今天排名（當下即時排名,正確）。

## 殘餘限制與參數陷阱

- 歷史股本庫 = 今天前 300 大：早年大公司若掉出今天前 300 仍缺 → 數字仍偏樂觀（可 --top-n 500 擴充）。
- **grid test 調出的參數（如 STOCK_NO=150）是在固定池上調的**——換誠實池後最優參數可能不同,必須重調,不得沿用。
- TWSE 法人資料 2017 前缺 → 法人動能 2015-2016 無法回測。

## 誠實池參數 grid 結論（2026-08-11，54 組掃描）

2022-2026-07 誠實池最佳單窗組合：**N=100 / LB=10 / FD=90 / BR=0.05 / MB=0.02 / BS=1 / TR=10 / SL=0.10** → +155.30%、回撤 17.69%、勝率 68.75%。

**但雙窗驗證全敗——無任何組合能兩窗皆正**：

| 組合 | 2022-2026-07 | 2015-2021 |
|---|---|---|
| N=150/FD120/BR0.08（舊） | +2.65% | +27.05% |
| N=100/FD90/BR0.05（22-26 最佳） | +155.30% | -23.71% |
| N=100/LB15/FD150/BR0.08 | +92.20% | -5.23% |
| N=100/LB15/FD120/BR0.05 | +129.64% | -30.08% |

教訓：
1. **參數調哪窗就過擬合哪窗**——2022-2026 偏好激進（FD90/BR0.05），2015-2021 偏好保守（FD120/BR0.08），兩窗的最優參數互斥。
2. 誠實池下法人動能是「市況決定成敗」的邊際策略，**不存在穩健配置**；固定池 +303.74% 的輝煌是倖存者偏差幻覺。
3. 後續若要繼續此策略，方向應是機制改良（進場/出場結構）而非參數微調；或接受其邊際性、控管資金配置。
